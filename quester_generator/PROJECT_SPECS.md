# Техническое задание и спецификация проекта: Quester Generator Pro

## 1. Общее описание
Это расширение существующего генератора квестов для WRobot (TBC 2.4.3). Основная цель — превратить узкоспециализированный инструмент в универсальную среду для создания «гигантских» квестовых профилей, включающих гринд, навигацию и поддержку множества зон.

## 2. Архитектура системы

### Уровень Данных (Core)
- **`core/models.py`**: Описывает модель проекта.
  - `ProjectState`: Корень проекта (фракция, список зон).
  - `ZoneProject`: Данные конкретной локации (выбранные квесты, задачи гринда, пути).
  - `GrindTask`: Описание задачи на фарм (MobID, Hotspots, Target Level).

### Уровень Логики (Logic)
- **`logic/session_manager.py`**: Отвечает за JSON-сериализацию. Сохраняет `ProjectState` в файл `project_session.json` при каждом изменении или закрытии.
- **`logic/coord_parser.py`**: Использует регулярные выражения для извлечения X, Y, Z из сырого текста WRobot (XML или Vector3).

### Уровень Доступа к Данным (Data Access)
- **`data_access/trainer_repo.py`**: SQL-запросы для поиска классовых тренеров (`NpcFlags & 16`).
- **`data_access/quests_repo.py`**: Добавлена загрузка поля `Details` для отображения описания.

### Уровень Интерфейса (UI)
- **`ui/app.py`**: Использует `ttk.Notebook`. Реализована динамическая загрузка вкладок.
- **`ui/zone_tab.py`**: Инкапсулирует логику Treeview квестов, списки Listbox для гринда и путей. Реализовано контекстное меню (правый клик) через `Toplevel` окна.

### Уровень Экспорта (Exporter)
- **`exporter/easy_quest_xml.py`**:
  - Агрегирует данные из всех зон проекта.
  - Реализует `QuestsSorted` в порядке: [Zone1 Quests -> Zone1 Grind -> Zone1 Paths -> Zone2 ...].
  - Автоматически собирает NPC, Вендоров, Флай-мастеров и Тренеров, исключая дубликаты по ID.
  - Генерирует корректные `EasyQuest` элементы для гриндеров и точек перемещения.

## 3. Требования к C# коду (Legacy Mode)
Все генерируемые скрипты должны соответствовать стандарту **C# 2.0 / .NET 3.5**:
- Явное указание типов (никаких `var`).
- Классические свойства (private field + public get/set).
- Отсутствие LINQ и лямбд.
- Отсутствие интерполяции строк.

## 4. Инструкция по запуску и тестированию
1. Установите зависимости: `pip install -r quester_generator/requirements.txt`.
2. Настройте БД в `quester_generator/config/db.yaml`.
3. Запустите тесты: `python3 quester_generator/tests/test_new_features.py`.
4. Запустите приложение: `python3 quester_generator/main.py`.
